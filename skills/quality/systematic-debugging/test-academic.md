# Scenario: Choosing an Investigation Path

Read `SKILL.md` in this directory and answer:

1. Which checks are still needed when the error and code already identify a simple issue?
2. What evidence can be used for an intermittent failure that cannot be reproduced consistently?
3. When should diagnostic logging be added or a reference implementation compared?
4. How should temporary service recovery and a root-cause fix be verified and reported separately?
5. How should the next experiment be chosen after the first hypothesis is disproved?

Explain the reasoning in light of the execution conditions. Do not judge effectiveness by reciting fixed phases or requiring a particular amount of time. This file is an evaluation prompt; it does not claim that behavioral tests have been run.
